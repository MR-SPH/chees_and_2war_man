# رقعة الحرب — مكتبة المخطوطات

موقع قراءة أدبي تفاعلي صُمّم لتقديم مخطوطة **رقعة الحرب** ومواد ملف التقديم إلى مختبر سرديات، ضمن تجربة أقرب إلى تصفّح كتاب ورقي.

## الفكرة

الموقع ليس معرض ملفات تقليديًا؛ إنه مكتبة رقمية تعرض الأعمال المنشورة على هيئة دفاتر وكتب، وتسمح للقارئ بفتح كل مادة وقراءتها صفحةً صفحة.

## المزايا

- تجربة قراءة هجينة: واجهة مكتبة حديثة ودفتر/كتاب بصفحات وتقليب.
- أحجام ورقية متعددة: A6 وA5 وB5 وA4، وأحجام كتب شائعة.
- صفحات مسطّرة أو سادة، وترقيم صفحات، والانتقال إلى صفحة محددة.
- تنقل بين مواد التقديم من داخل وضع القراءة.
- مواد مصنفة: المخطوطة، Logline، Synopsis، Treatment، المشهد النموذجي، والسيرة الذاتية.
- وضع كتابة خاص لإدارة الدفاتر وتحديد ما يظهر للجنة.
- تصدير PDF عبر نافذة الطباعة، وتصدير TXT، واستيراد/نشر المواد عبر ملف JavaScript.
- يعمل على GitHub Pages دون خادم خلفي.

## النشر على GitHub Pages

1. من إعدادات المستودع افتح **Settings → Pages**.
2. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. احفظ الإعداد وانتظر اكتمال النشر.
4. الصفحة الرئيسية هي `index.html`.

## إدارة المواد

- افتح الموقع مع اللاحقة `#write` للدخول إلى وضع الكتابة.
- أنشئ دفترًا أو كتابًا لكل مادة من مواد التقديم.
- من زر النشر حدّد المواد التي تريد أن تراها لجنة التقييم.
- اضغط **تصدير للنشر** لتنزيل `stories.js`.
- ارفع الملف الناتج إلى جذر المستودع مع استبدال الملف الحالي.
- المواد المنشورة في `stories.js` هي التي تظهر للزوار؛ المسودات الخاصة لا تُصدّر.

> ملاحظة: وضع الكتابة يحفظ محليًا في المتصفح والجهاز الحالي. لا توجد مزامنة سحابية. احتفظ بنسخة من `stories.js` وملفات التصدير كنسخة احتياطية.
