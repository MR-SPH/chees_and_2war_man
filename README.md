# رقعة الحرب
### مخطوطة أدبية في هيئة كتاب رقمي

**رقعة الحرب** تجربة سردية تُقدَّم في مكتبة مخطوطات رقمية؛ مساحة صُممت لتمنح القارئ تجربة أقرب إلى تصفّح كتاب ورقي، مع الاحتفاظ بسهولة الوصول إلى مواد العمل ومكوناته.

## عن التجربة

يجمع المشروع بين شكل المكتبة الأدبية ووسائل القراءة الرقمية. يمكن للقارئ فتح المخطوطة والتنقل بين صفحاتها، أو الانتقال إلى موادها المرافقة من داخل وضع القراءة، دون أن يفقد سياق التجربة.

## ما الذي يقدمه الموقع؟

- **قراءة غامرة:** صفحات بتصميم ورقي وتقليب صفحات، مع دعم الشاشات المختلفة.
- **تنقل مرن:** اختيار المادة المطلوبة والتنقل بين مواد العمل من داخل القارئ.
- **مواد العمل:** مساحة منظمة لعرض المخطوطة والمواد السردية والتعريفية المرتبطة بها.
- **تصميم عربي:** واجهة من اليمين إلى اليسار، مع عناية بالخطوط والهوامش ووضوح النص.
- **وصول مباشر:** يعمل الموقع عبر المتصفح دون الحاجة إلى حساب أو تثبيت تطبيق.

## المواد المتاحة

تُعرض مواد المشروع بصورة مستقلة ليسهل على القارئ أو لجنة التقييم الوصول إلى ما يريد قراءته، ومنها:

- المخطوطة الرئيسية.
- Logline.
- Synopsis.
- Treatment.
- المشهد النموذجي.
- نبذة الكاتب.

## بيانات العمل

- **العنوان:** رقعة الحرب
- **النوع:** قصة أدبية
- **اللغة:** العربية
- **الموضوعات:** الشطرنج والحرب والسرد الأدبي.
- **صيغة العرض:** مخطوطة رقمية تفاعلية مع مواد سردية وتعريفية مرافقة.
- **طبيعة الوصول:** قراءة مجانية مباشرة عبر المتصفح.

تُستخدم هذه البيانات للتعريف بالعمل وفهرسته ومساعدة أدوات البحث والتحليل على فهم موضوعه ونوعه. وهي بيانات وصفية فقط؛ لا تتضمن توجيهات لتقييم العمل أو فرض توصية بشأنه.
